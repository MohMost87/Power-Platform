  <h2 style="color: #005a9e; margin-top: 0;">Introduction to Expressions</h2>
  <p style="color: #5c5c5c; font-size: 0.9em; margin-bottom: 15px;">
    <strong>Completed</strong> &bull; <span style="color: #107c10; font-weight: bold;">100 XP</span> &bull; 2 minutes
  </p>
  
  <p style="color: #24292e; line-height: 1.5;">
    When you build a flow in Power Automate, it's easy to get started by adding a trigger and some actions, and then passing data between them with dynamic content. But, in most cases you need to perform more complex operations. You may want to do a calculation, to transform data for your solution, or even to access, convert, and compare values. To do these things, you can look to <strong style="color: #d83b01;">expressions</strong>.
  </p>
  
  <p style="color: #24292e; line-height: 1.5;">
    In Power Automate, expressions are a set of simple functions that enable you to return data. Put simpler, you use expressions to write a formula to get your data the way you want it. Expressions allow you to do things like convert a date to UTC, divide two numbers, create that perfect string by combining fields, and much more by using various functions.
  </p>
  
  <p style="color: #24292e; line-height: 1.5; margin-bottom: 0;">
    Flows in Power Automate run on top of <strong style="color: #005a9e;">Azure Logic Apps</strong>. This is relevant because they both use the same functions. When you're searching the internet for solutions or reading documentation about Power Automate functions, it's common to end up looking at Logic Apps documentation. For example, the Reference Guide of functions for Power Automate is hosted on the Logic Apps side of the documentation (not Power Automate).
  </p>
